Cookie Clicker Bot 🍪
A Python automation project that uses Selenium WebDriver to play Cookie Clicker automatically. The bot clicks the big cookie, checks the store every 5 seconds, and purchases the most expensive available upgrade it can afford.
Features
Opens Cookie Clicker in Google Chrome.
Selects English when the language selection screen appears.
Automatically clicks the big cookie.
Checks available store products every 5 seconds.
Purchases the most expensive affordable product.
Runs for 5 minutes.
Prints the final cookie count.
